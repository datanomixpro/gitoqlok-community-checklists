# Community checklists for PowerBI
[Gitoqlok](https://chromewebstore.google.com/detail/gitoqlok-qlik-and-powerbi/kkgicbgpgfcbhcbmifmfagggnpkebdaj?hl=en), [Soterre DevOps Analytics Extension](https://chromewebstore.google.com/detail/soterre-devops-analytics/lkcajdpjbhibjchgodbdionjplkmihej?hl=en)

The Application Checklist is a list of things to verify before an app goes to production: data model hygiene, visualization performance, naming, documentation. Gitoqlok ships a default checklist and community checklists; you can write your own and share them.
